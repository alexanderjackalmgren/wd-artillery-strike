# WD Artillery Strike

Fast mortar / SPH-2 range calculator for [WARDOGS](https://store.steampowered.com/app/2166060/WARDOGS/).

**Live:** https://alexanderjackalmgren.github.io/wd-artillery-strike/

Paste gun and target coordinates, get distance and elevation MIL. L81 sight guide included. Works on desktop and phone.

## GitHub Pages

This repo is a static site (`index.html` at the root).

1. Push to `main`
2. Repo **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**
4. Branch: `main` / `/ (root)` → Save

Site URL: `https://<user>.github.io/wd-artillery-strike/`
