# WD Artillery Strike

Range computer for [WARDOGS](https://store.steampowered.com/app/2166060/WARDOGS/) — L81 mortar and SPH-2 artillery.

**Use it:** https://alexanderjackalmgren.github.io/wd-artillery-strike/

## What it does

1. Paste (or type) your mortar grid from squad chat — it stays saved in the browser.
2. Paste the target grid.
3. Read distance in **meters** or **MIL**, plus a range badge (mortar / dead zone / SPH-2 / out of range).
4. For the L81, match the gold **SET HERE** line on the in-page sight ladder to your optic.
5. Open **How to fire** for a short illustrated walkthrough (mark → copy → paste → ping → dial).

Coordinates are game order (**Y** then **X**). Flat-ground estimates — always fire a ranging shot.
